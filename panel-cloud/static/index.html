You keep the key.

Your Speexx password is encrypted on disk and never written to a log, a URL, or the page. It is decrypted for the few seconds a run starts, then dropped.

What a run actually does.

Step three

Done

When the level runs out it stops on its own and tells you it is done.

Safe by construction, not by luck.

A wrong password stops dead

Credentials are checked before a run starts. A wrong password is never resubmitted — that is what locks an address out of the portal — and that account is paused for a while instead.

Runs are kept apart

Each run gets its own browser fingerprint and starts at least fifteen seconds after the last one, so simultaneous logins never look like an attack.

Yours stays yours

Every query is filtered by account on the server. There is no URL that shows you somebody else's saved login or run.

Nothing leaks into logs

Passwords are passed in on standard input, never on a command line, and are scrubbed out of everything that gets written down.
